# 📱 Como Instalar o App no Celular

## ✅ O que foi corrigido:

- ✅ Componente de instalação agora aparece automaticamente no dashboard
- ✅ Prompt aparece após 2 segundos na primeira visita
- ✅ Instruções manuais disponíveis se o prompt automático não aparecer

## 📲 Instalação no Android (Chrome)

### Método 1: Prompt Automático (Recomendado)
1. Acesse o site: `https://contrato-six.vercel.app`
2. Aguarde 2 segundos - um card aparecerá no canto inferior direito
3. Toque em **"Instalar Agora"**
4. Confirme a instalação

### Método 2: Menu do Chrome
1. Abra o site no Chrome
2. Toque nos **três pontos** (⋮) no canto superior direito
3. Procure por **"Adicionar à tela inicial"** ou **"Instalar app"**
4. Toque e confirme

### Método 3: Banner do Chrome
1. Abra o site no Chrome
2. Se aparecer um banner na parte inferior da tela pedindo para instalar, toque em **"Instalar"** ou **"Adicionar"**

## 🍎 Instalação no iPhone/iPad (Safari)

1. Abra o site no Safari: `https://contrato-six.vercel.app`
2. Toque no botão **Compartilhar** (⎋) na barra inferior
3. Role para baixo e toque em **"Adicionar à Tela de Início"**
4. Personalize o nome (opcional) e toque em **"Adicionar"**

## 💻 Instalação no Desktop (Chrome/Edge)

1. Abra o site no navegador
2. Procure pelo ícone de **instalação** na barra de endereços (ao lado da URL)
3. Clique no ícone e selecione **"Instalar"**

## 🔍 Se o Prompt Não Aparecer

### Verificações:
1. ✅ Certifique-se de estar usando **Chrome** no Android ou **Safari** no iPhone
2. ✅ Acesse via **HTTPS**: `https://contrato-six.vercel.app`
3. ✅ Limpe o cache do navegador (veja `COMO-LIMPAR-CACHE.md`)
4. ✅ Feche e abra o navegador novamente

### Instalação Manual (Sempre Funciona):

**Android:**
1. Menu (⋮) → **"Adicionar à tela inicial"**
2. Ou: Menu → **"Instalar app"**

**iPhone:**
1. Botão Compartilhar (⎋) → **"Adicionar à Tela de Início"**

## ✅ Como Verificar se Está Instalado

- O app aparecerá na tela inicial do celular
- Ao abrir, não terá a barra de endereços do navegador
- Funcionará como um app nativo

## 🆘 Problemas Comuns

### "Não consigo encontrar a opção de instalar"
- Use Chrome no Android ou Safari no iPhone
- Certifique-se de estar em HTTPS
- Limpe o cache e tente novamente

### "O prompt aparece mas não instala"
- Verifique sua conexão com internet
- Tente fechar e abrir o navegador
- Use o método manual (menu do navegador)

### "Já instalei mas não aparece na tela inicial"
- Procure na pasta de apps ou na gaveta de apps
- No Android, pode estar em "Apps instalados recentemente"

## 📝 Notas

- O prompt automático pode não aparecer se você já dispensou antes (aparece novamente após 7 dias)
- Alguns navegadores podem bloquear o prompt automático por políticas de privacidade
- A instalação manual sempre funciona, independente do navegador
