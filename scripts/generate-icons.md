# Gerar Ícones PWA

Para gerar os ícones necessários para o PWA, você pode:

## Opção 1: Usar um gerador online
1. Acesse: https://www.pwabuilder.com/imageGenerator
2. Faça upload de uma imagem (mínimo 512x512px)
3. Baixe os ícones gerados
4. Coloque em `public/`:
   - `icon-192.png` (192x192px)
   - `icon-512.png` (512x512px)

## Opção 2: Criar manualmente
Use qualquer editor de imagem para criar:
- `public/icon-192.png` - 192x192 pixels
- `public/icon-512.png` - 512x512 pixels

## Opção 3: Usar um ícone temporário
Por enquanto, você pode usar o favicon existente como base.

## Ícone sugerido
- Fundo: Gradiente azul/roxo
- Texto: "C" ou "CT" em branco
- Estilo: Moderno e minimalista
